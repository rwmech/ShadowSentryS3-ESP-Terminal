ShadowSentry S3: boot sequence and the SUBSYS / about screen, preview only

Press "Play boot sequence": the logo shows, fades out, the LCARS frame rolls in piece by piece (elbows, bars, rail buttons, strip), then the page content appears. Tap the bottom-left elbow (labelled SUBSYS) for the about screen, styled after the First Contact manual-input panel: red on black, a header bar, a big title, terminal lines, a row of small buttons. The logo is an original ShadowSentry insignia, not the Starfleet delta. Not built.

The pieces

  • Button: the bottom-left elbow becomes 07 SUBSYS. It is 70 x 34 px, a far easier touch target than a small button by the clock (the bottom band is only 10 to 14 px tall), and an elbow as a button is very LCARS. The clock stays where it is.
  • About screen: red on black after the First Contact manual-input panel: header bar, logo, big title, terminal lines (unit, base project and licence, fork, build, node, an "access code" built from the date and the board's address), a blinking cursor, a row of small buttons; RETURN goes back. Live values come from the board.
  • Logo: an original insignia (a shield with a chevron and a sentry eye), drawn in the palette. You can upload your own PNG from the dashboard; the board uses it on the boot screen and the about screen, and falls back to this one if none is uploaded.
  • Boot: the logo fades in, holds about 1.5 s, fades out; then the frame rolls in, each piece sliding from its edge 60 ms after the one before (about 0.9 s in all); then the page content fades in. Under 4 s in all, while the board is still bringing up Wi-Fi anyway.
  • Image path on the board: a PNG uploaded on the Settings page is saved to /sd/ui/logo.png and decoded once at boot into PSRAM (LVGL's PNG decoder, one sdkconfig option). Suggested sizes: 200 x 200 for the boot logo, the same file scaled down for the about screen; transparent background.
